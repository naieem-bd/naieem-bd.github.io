## What's inside

| Path | Description |
|---|---|
| `index.html`, `style.css`, `assets/` | Main portfolio site |
| `neon/` | Neon landing page demo |
| `siktop/` | Siktop social-dashboard UI demo (profile, posts, analytics, settings pages) |
| `tagsbay/` | Tagsbay UI demo |
| `Resume_of_Naieemur_Rahman*.pdf` / `.docx` | Downloadable resume |

## Running locally

It's a static site, so no build step is needed:

```bash
git clone https://github.com/naieem-bd/naieem-bd.github.io.git
cd naieem-bd.github.io
# open index.html in a browser, or serve it:
npx serve .
```

## Deployment

Hosted on GitHub Pages. Every push to `main` is published automatically.
